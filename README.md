# Direct Materials

Сервис автоматической выдачи материалов через Instagram Direct. Связывает реакцию на публикацию с персональной доставкой материала и помогает автоматизировать коммуникацию с аудиторией.

## Возможности

- Кампании для конкретной публикации, любой публикации и следующего поста.
- Сопоставление комментариев с ключевыми словами, публичные ответы и доставка в Direct.
- Официальный OAuth, React-панель управления и фоновая обработка Instagram-событий.

## Инженерные акценты

- Полный цикл бизнес-автоматизации: интерфейс, внешний API, хранение состояния и обработка событий.
- Разделение приёма webhook и фоновой работы через очередь.
- Настройка кампаний через интерфейс вместо ручной обработки каждого обращения.

## Стек

React, TypeScript, Hono, TanStack Query, Tailwind CSS, Vite, Vitest.
