# Direct Materials — автоматическая выдача материалов в Instagram

Сервис превращает комментарий с ключевым словом в доставку материала через Instagram Direct. Автор настраивает кампанию в панели управления, а обработка комментариев, публичный ответ и отправка материала выполняются автоматически.

## Как работает сценарий

1. Подключение Instagram через официальный OAuth.
2. Настройка ключевого слова, ответа и материала для конкретной публикации, любой публикации или следующего поста.
3. Приём Instagram webhook и передача события в очередь.
4. Сопоставление комментария с кампанией, публичный ответ и доставка в Direct с сохранением состояния операции.

React-панель объединяет настройку кампаний и работу с подключением Instagram. Backend на Cloudflare Workers использует Hono, D1 и Queues.

## Что показывает проект

Полный цикл автоматизации маркетингового процесса: интерфейс управления, OAuth, внешние API, webhook, очередь и база данных. Приём событий отделён от фоновой доставки, а предметные модули — от инфраструктуры. Это релевантно разработке SaaS, CRM-интеграций, ботов и сервисов автоматизации коммуникаций.

## Разработка

Node.js 24, pnpm@11.15.1.

```sh
pnpm install
pnpm dev
```

```sh
pnpm check
pnpm build
```

`check` объединяет форматирование, lint, проверку архитектурных границ, типов и тестов; тесты разделены на unit, Worker и React.
